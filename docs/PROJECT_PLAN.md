# 基于粒子群优化算法的投资组合风险-收益均衡决策系统项目计划

## 1. 文档目的

本文档用于冻结项目范围、建模口径、技术路线和阶段计划，作为后续后端、前端、实验报告与答辩材料的开发依据。

当前阶段只进行项目规划与文档冻结，不进入业务代码开发。

## 2. 项目定位

本项目面向“投资组合优化”课程任务。系统帮助投资者在有限资金约束下，从多只股票中确定投资权重，使组合在风险可控的前提下追求更高收益。

系统不是实盘交易系统，不提供投资建议，不接入真实下单链路。项目重点是数学建模、PSO 优化算法实现、风险-收益结果展示和实验分析。

## 3. 核心问题定义

### 3.1 输入

- 股票池：`N` 只股票。
- 历史价格或收益率数据。
- 期望收益向量：`mu = [mu1, mu2, ..., muN]`。
- 协方差矩阵：`Sigma`。
- 无风险收益率：`Rf`，默认可设为 `0`，后续通过接口或配置调整。
- PSO 参数：粒子数量、迭代次数、惯性权重、个体学习因子、群体学习因子、随机种子。

### 3.2 决策变量

每个粒子表示一个投资组合权重向量：

```text
w = [w1, w2, ..., wN]
```

其中 `wi` 表示第 `i` 只股票在组合中的资金占比。

### 3.3 约束条件

```text
wi >= 0
sum(wi) = 1
```

项目采用不允许卖空、资金全部投入的长仓组合约束。

### 3.4 目标函数

目标是最大化 Sharpe Ratio：

```text
Sharpe Ratio = (E(Rp) - Rf) / sigma_p
E(Rp) = w^T mu
sigma_p = sqrt(w^T Sigma w)
```

PSO 内部可将最大化问题转化为最小化 `-Sharpe Ratio`，但对外文档和界面统一表述为“最大化 Sharpe Ratio”。

### 3.5 股票选择解释规则

PSO 优化变量始终是连续权重。优化完成后，通过阈值解释股票是否被选择：

```text
若 wi >= 1%，则认为第 i 只股票被选入组合
若 wi < 1%，则认为第 i 只股票未被实质选入组合
```

该阈值只用于结果解释和前端展示，不参与 PSO 搜索约束。

## 4. 技术路线

### 4.1 后端

- Python
- FastAPI
- NumPy
- Pandas

后端职责：

- 读取和清洗股票数据。
- 计算收益率、期望收益、协方差矩阵。
- 手写 PSO 核心算法。
- 计算组合收益率、波动率、Sharpe Ratio。
- 提供优化、结果查询和图表数据接口。

### 4.2 前端

- Vue 3
- Element Plus
- ECharts

前端职责：

- 展示股票池和参数输入控件。
- 展示最优投资组合权重。
- 展示风险-收益散点图。
- 展示 PSO 迭代收敛曲线。
- 展示组合中被选择股票及对应权重。

### 4.3 算法约束

PSO 核心算法必须手写，不允许使用以下黑盒优化库：

- `scipy.optimize`
- `pyswarms`
- 其他直接完成 PSO 或投资组合优化的黑盒优化库

允许使用 NumPy 和 Pandas 进行矩阵运算、数据处理和指标计算。

## 6. 阶段计划

目标：

- 建立投资组合数学模型。

## 8. 关键风险与控制措施

### 8.1 数据质量风险

风险：缺失值、停牌、异常价格会影响收益率和协方差计算。

控制措施：

- 明确缺失值处理规则。
- 保留数据处理日志或摘要。
- 在报告中说明数据范围和处理方式。

### 8.2 约束处理风险

风险：PSO 更新后权重可能出现负数或总和不为 1。

控制措施：

- 每次位置更新后进行非负截断和归一化。
- 对全零向量使用均匀权重兜底。
- 在测试中检查权重约束。

### 8.3 算法解释风险

风险：连续权重优化与“是否选择股票”的离散表述混淆。

控制措施：

- 文档、接口和前端统一说明：PSO 优化连续权重。
- 1% 阈值只用于结果解释，不用于优化约束。

### 8.4 过度开发风险

风险：引入实盘交易、用户系统、复杂权限等超出课程任务的功能。

控制措施：

- 项目仅服务课程展示。
- 优先完成模型、算法、接口、图表和报告。
- 不开发交易、登录、持仓同步、自动调仓等非必要功能。

## 9. 当前冻结结论

- 目标函数冻结为最大化 Sharpe Ratio。
- 股票选择解释冻结为 `wi >= 1%`。
- 后端技术栈冻结为 Python + FastAPI + NumPy + Pandas。
- 前端技术栈冻结为 Vue 3 + Element Plus + ECharts。

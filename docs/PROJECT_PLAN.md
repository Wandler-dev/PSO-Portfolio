# 基于粒子群优化算法的投资组合风险-收益均衡决策系统项目计划

## 1. 文档目的

本文档用于冻结项目范围、建模口径、技术路线和阶段计划，作为后续后端、前端、实验报告与答辩材料的开发依据。

当前阶段只进行项目规划与文档冻结，不进入业务代码开发。

## 2. 项目定位

本项目面向“投资组合优化”课程任务。系统帮助投资者在有限资金约束下，从多只股票中确定投资权重，使组合在风险可控的前提下追求更高收益。

系统不是实盘交易系统，不提供投资建议，不接入真实下单链路。项目重点是数学建模、PSO 优化算法实现、风险-收益结果展示和实验分析。

## 3. 核心问题定义

### 3.1 输入

- 股票池：`N` 只股票。
- 历史价格或收益率数据。数据源优先级为：课程要求提供的 UCI Stock Portfolio Performance 数据集；若网络访问、字段含义或数据可用性问题导致无法使用，则降级使用本地样例数据或模拟数据，并在实验报告中说明降级原因。
- 期望收益向量：`mu = [mu1, mu2, ..., muN]`。
- 协方差矩阵：`Sigma`。
- 无风险收益率：`Rf`，默认可设为 `0`，后续通过接口或配置调整。
- PSO 参数：粒子数量、迭代次数、惯性权重、个体学习因子、群体学习因子、随机种子。

### 3.2 决策变量

每个粒子表示一个投资组合权重向量：

```text
w = [w1, w2, ..., wN]
```

其中 `wi` 表示第 `i` 只股票在组合中的资金占比。

### 3.3 约束条件

```text
wi >= 0
sum(wi) = 1
```

项目采用不允许卖空、资金全部投入的长仓组合约束。

### 3.4 目标函数

目标是最大化 Sharpe Ratio：

```text
Sharpe Ratio = (E(Rp) - Rf) / volatility
E(Rp) = w^T mu
volatility = sqrt(w^T Sigma w)
```

PSO 内部可将最大化问题转化为最小化 `-Sharpe Ratio`，但对外文档和界面统一表述为“最大化 Sharpe Ratio”。

若输入为日度价格数据，默认使用 252 个交易日进行年化：

```text
mu_annual = mean_daily_return * 252
Sigma_annual = cov_daily_return * 252
```

后续指标计算默认使用年化后的 `mu_annual` 和 `Sigma_annual`。外部 API 和前端字段统一使用 `volatility` 表示组合风险/波动率；报告中可解释为“风险，即组合波动率”。

### 3.5 展示基线

风险-收益散点图默认使用 Monte Carlo 随机组合 baseline 生成，不少于 2000 个随机组合。PSO 找到的最优组合必须在散点图中高亮标记，便于对比 PSO 解与随机组合分布的位置。

### 3.6 数据源优先级

- V1 优先使用课程要求提供的 UCI Stock Portfolio Performance 数据集。
- 若网络访问失败、字段不适配或下载不稳定，则使用 `data/sample/` 下的本地样例数据。
- 阶段一算法原型允许使用模拟数据，但报告中必须标注“模拟数据”。
- 系统需要在输出中记录 `data_source` 字段，说明当前结果来自 `uci`、本地样例或模拟数据。

### 3.7 年化规则

- 若输入为日度价格数据，先计算日收益率。
- 默认使用 252 个交易日进行年化。
- `mu_annual = mean_daily_return * 252`。
- `Sigma_annual = cov_daily_return * 252`。
- 若数据本身已是年化指标，则不得重复年化，必须在数据说明中标注。

### 3.8 股票选择解释规则

PSO 优化变量始终是连续权重。优化完成后，通过阈值解释股票是否被选择：

```text
若 wi >= 1%，则认为第 i 只股票被选入组合
若 wi < 1%，则认为第 i 只股票未被实质选入组合
```

该阈值只用于结果解释和前端展示，不参与 PSO 搜索约束。

## 4. 技术路线

### 4.1 后端

- Python
- FastAPI
- NumPy
- Pandas

后端职责：

- 读取和清洗股票数据。
- 计算收益率、期望收益、协方差矩阵。
- 手写 PSO 核心算法。
- 计算组合收益率、`volatility`、Sharpe Ratio。
- 提供优化、结果查询和图表数据接口。

### 4.2 前端

- Vue 3
- Element Plus
- ECharts

前端职责：

- 展示股票池和参数输入控件。
- 展示最优投资组合权重。
- 展示 Monte Carlo 随机组合风险-收益散点图，并高亮 PSO 最优组合。
- 展示 PSO 迭代收敛曲线。
- 展示组合中被选择股票及对应权重。

### 4.3 算法约束

PSO 核心算法必须手写，不允许使用以下黑盒优化库：

- `scipy.optimize`
- `pyswarms`
- 其他直接完成 PSO 或投资组合优化的黑盒优化库

允许使用 NumPy 和 Pandas 进行矩阵运算、数据处理和指标计算。

## 6. 阶段计划

### 阶段一：后端算法原型

目标：

- 建立投资组合数学模型。
- 使用 NumPy 手写 PSO 算法。
- 在固定样例数据或小型 CSV 数据上完成优化。

交付物：

- 权重归一化与非负约束处理逻辑。
- Sharpe Ratio 适应度函数。
- PSO 迭代过程与最优解输出。
- 基础测试或可重复运行的实验脚本。

验收重点：

- 输出权重满足 `wi >= 0` 且 `sum(wi) = 1`。
- 最优组合能输出收益率、`volatility`、Sharpe Ratio。
- 随机种子固定时结果可复现。
- 未使用黑盒优化库。

### 阶段二：真实数据接入

目标：

- 优先接入课程要求提供的 UCI Stock Portfolio Performance 数据集。
- 若 UCI 数据因网络或字段问题无法使用，降级使用本地样例数据或模拟数据。
- 形成标准化收益率数据处理流程。

交付物：

- 股票价格数据读取流程。
- 缺失值处理规则。
- 日收益率或周期收益率计算。
- 日度收益率按 252 个交易日年化的计算流程。
- 期望收益向量与协方差矩阵计算。

验收重点：

- 输入数据结构清晰。

## 7. 数据流

```text
UCI Stock Portfolio Performance 数据集或降级数据
  -> 数据清洗
  -> 日收益率矩阵
  -> 年化期望收益向量 mu_annual 和年化协方差矩阵 Sigma_annual

```

## 8. 关键风险与控制措施

### 8.1 数据质量风险

风险：缺失值、停牌、异常价格会影响收益率和协方差计算。

控制措施：

- 优先使用课程要求提供的 UCI Stock Portfolio Performance 数据集。
- 若 UCI 数据不可用，使用本地样例数据或模拟数据降级，并在报告中说明。
- 明确缺失值处理规则。
- 保留数据处理日志或摘要。
- 在报告中说明数据范围和处理方式。

### 8.2 约束处理风险

风险：PSO 更新后权重可能出现负数或总和不为 1。

控制措施：

- 每次位置更新后进行非负截断和归一化。
- 对全零向量使用均匀权重兜底。
- 在测试中检查权重约束。

### 8.3 算法解释风险

风险：连续权重优化与“是否选择股票”的离散表述混淆。

控制措施：

- 文档、接口和前端统一说明：PSO 优化连续权重。
- 1% 阈值只用于结果解释，不用于优化约束。

### 8.4 过度开发风险

风险：引入实盘交易、用户系统、复杂权限等超出课程任务的功能。

控制措施：

- 项目仅服务课程展示。
- 优先完成模型、算法、接口、图表和报告。
- 不开发交易、登录、持仓同步、自动调仓等非必要功能。

## 9. 当前冻结结论

- 决策变量冻结为连续投资权重向量 `w`。
- 约束冻结为 `wi >= 0` 且 `sum(wi) = 1`。
- 目标函数冻结为最大化 Sharpe Ratio。
- 数据源优先级冻结为 UCI Stock Portfolio Performance 数据集优先，必要时降级到本地样例数据或模拟数据。
- 日度价格数据冻结为按 252 个交易日年化。
- 外部 API 和前端字段冻结为使用 `volatility` 表示组合风险/波动率。
- 风险-收益散点图冻结为默认使用不少于 2000 个 Monte Carlo 随机组合，并高亮 PSO 最优组合。
- 股票选择解释冻结为 `wi >= 1%`。
- 后端技术栈冻结为 Python + FastAPI + NumPy + Pandas。
- 前端技术栈冻结为 Vue 3 + Element Plus + ECharts。
- PSO 核心算法冻结为手写实现，不使用黑盒优化库。

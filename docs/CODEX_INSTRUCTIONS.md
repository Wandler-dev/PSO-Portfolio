## 4. 当前冻结的项目口径

### 4.1 决策变量

投资组合权重向量：

```text
w = [w1, w2, ..., wN]
```

每个粒子表示一个连续权重向量。

### 4.2 约束条件

```text
wi >= 0
sum(wi) = 1
```

项目采用长仓、全额投资约束。

### 4.3 目标函数

最大化 Sharpe Ratio：

```text
Sharpe Ratio = (E(Rp) - Rf) / sigma_p
sigma_p = sqrt(w^T Sigma w)
```

### 4.4 股票选择解释

优化结束后使用 1% 权重阈值解释股票是否被选择：

```text
wi >= 0.01 表示选择该股票
wi < 0.01 表示未实质选择该股票
```

该阈值只用于结果解释，不参与优化搜索。

## 6. 明确禁止事项

禁止使用以下方式绕过课程算法要求：

- 使用 `scipy.optimize` 直接求解投资组合优化。
- 使用 `pyswarms` 或其他 PSO 黑盒库。
- 使用任何直接封装投资组合优化目标和约束的黑盒优化库。
- 将 1% 阈值误写为优化约束。
- 将离散选股问题替代连续权重优化问题。

禁止扩展的非课程功能：

- 登录注册系统。
- 实盘交易。
- 自动下单。
- 券商接口。
- 用户资产持仓同步。
- 复杂权限管理。

## 7. 后端开发指导

后端实现应保持以下边界：

- 数据处理逻辑负责读取价格数据、清洗数据、计算收益率。
- 指标逻辑负责计算期望收益、协方差、波动率、Sharpe Ratio。
- PSO 逻辑只负责搜索最优权重。
- 服务层负责串联数据处理、优化和响应结构。
- API 层只负责参数接收、校验和响应返回。

PSO 实现要求：

- 初始化粒子权重后必须归一化。
- 每次位置更新后必须执行非负处理和归一化。
- 适应度函数必须处理 `sigma_p = 0` 或接近 0 的情况。
- 固定随机种子时结果应可复现。
- 应记录每轮全局最优值，用于收敛曲线。

- 权重非负。

- 页面能正常启动。
- 图表能渲染非空数据。

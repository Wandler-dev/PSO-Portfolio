## 4. 当前冻结的项目口径

### 4.1 决策变量

投资组合权重向量：

```text
w = [w1, w2, ..., wN]
```

每个粒子表示一个连续权重向量。

### 4.2 约束条件

```text
wi >= 0
sum(wi) = 1
```

项目采用长仓、全额投资约束。

### 4.3 目标函数

最大化 Sharpe Ratio：

```text
Sharpe Ratio = (E(Rp) - Rf) / volatility
volatility = sqrt(w^T Sigma w)
```

### 4.4 数据源优先级

项目优先使用课程要求提供的 UCI Stock Portfolio Performance 数据集。若网络访问、字段含义或数据可用性问题导致无法使用，则降级使用本地样例数据或模拟数据，并在实验报告中说明降级原因、替代数据来源和实验限制。

### 4.5 时间尺度和年化口径

若输入为日度价格数据，默认按 252 个交易日进行年化：

```text
mu_annual = mean_daily_return * 252
Sigma_annual = cov_daily_return * 252
```

后续组合收益、组合风险和 Sharpe Ratio 默认基于年化后的 `mu_annual` 和 `Sigma_annual` 计算。

### 4.6 字段命名

外部 API 和前端字段统一使用 `volatility` 表示组合风险/波动率。报告中可以写作“风险，即组合波动率”，但接口和前端数据结构不得混用 `risk`、`sigma`、`std` 等字段名表示同一含义。

### 4.7 展示基线

风险-收益散点图默认由不少于 2000 个 Monte Carlo 随机组合生成，PSO 最优组合必须高亮标记。

### 4.8 股票选择解释

优化结束后使用 1% 权重阈值解释股票是否被选择：

```text
wi >= 0.01 表示选择该股票
wi < 0.01 表示未实质选择该股票
```

该阈值只用于结果解释，不参与优化搜索。

## 6. 明确禁止事项

禁止使用以下方式绕过课程算法要求：

- 使用 `scipy.optimize` 直接求解投资组合优化。
- 使用 `pyswarms` 或其他 PSO 黑盒库。
- 使用任何直接封装投资组合优化目标和约束的黑盒优化库。
- 将 1% 阈值误写为优化约束。
- 将离散选股问题替代连续权重优化问题。
- 将 Monte Carlo 随机组合 baseline 当作 PSO 优化结果。
- 在 API 或前端中混用 `risk`、`sigma`、`std` 表示组合波动率字段；统一使用 `volatility`。

## 7. 后端开发指导

后端实现应保持以下边界：

- 数据处理逻辑负责按优先级读取 UCI Stock Portfolio Performance 数据集；无法使用时降级读取本地样例数据或模拟数据，并保留降级说明。
- 数据处理逻辑负责清洗价格数据、计算日收益率，并在日度输入下按 252 个交易日年化。
- 指标逻辑负责计算期望收益、协方差、`volatility`、Sharpe Ratio。
- PSO 逻辑只负责搜索最优权重。
- 服务层负责串联数据处理、优化和响应结构。
- API 层只负责参数接收、校验和响应返回，组合风险/波动率字段统一命名为 `volatility`。

PSO 实现要求：

- 初始化粒子权重后必须归一化。
- 每次位置更新后必须执行非负处理和归一化。
- 适应度函数必须处理 `volatility = 0` 或接近 0 的情况。
- 固定随机种子时结果应可复现。
- 应记录每轮全局最优值，用于收敛曲线。
- Monte Carlo 随机组合 baseline 应与 PSO 优化流程分离，只用于风险-收益散点图展示和对比。

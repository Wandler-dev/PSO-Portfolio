# 基于粒子群优化算法的投资组合风险-收益均衡决策系统修订版立项说明

## 1. 项目名称

基于粒子群优化算法的投资组合风险-收益均衡决策系统

## 2. 课程任务背景

投资组合优化是金融工程和运筹优化中的经典问题。投资者通常拥有有限资金，需要在多种股票之间分配投资比例，使组合收益尽可能高，同时控制整体风险。

本项目围绕课程任务要求，建立投资组合优化模型，明确决策变量、目标函数和约束条件，并使用粒子群优化算法求解。系统最终通过可视化界面展示投资组合权重、风险-收益散点图、PSO 收敛过程和股票选择结果。

## 3. 研究与实现目标

本项目目标包括：

- 建立符合课程要求的投资组合优化数学模型。
- 使用手写 PSO 算法优化股票投资权重。
- 根据最优权重计算组合收益率、`volatility` 和 Sharpe Ratio。
- 使用 1% 权重阈值解释股票是否被选择。
- 通过 FastAPI 提供优化结果。
- 通过 Vue 3 + Element Plus + ECharts 展示优化结果和实验图表。
- 形成可用于答辩的实验报告和系统演示。

## 4. 数据源与时间尺度

项目优先使用课程要求提供的 UCI Stock Portfolio Performance 数据集。若网络访问、字段含义或数据可用性问题导致 UCI 数据无法使用，则降级使用 `data/sample/` 下的本地样例数据，并在实验报告中说明降级原因、替代数据来源和实验限制。阶段一算法原型可使用模拟数据，但不得将模拟数据结果作为真实数据实验结论。

若输入为日度价格数据，默认先计算日收益率，再按 252 个交易日进行年化：

```text
mu_annual = mean_daily_return * 252
Sigma_annual = cov_daily_return * 252
```

后续组合收益、组合风险和 Sharpe Ratio 默认基于年化后的 `mu_annual` 和 `Sigma_annual` 计算。

## 5. 数学模型

### 5.1 决策变量

设股票池包含 `N` 只股票，每个投资组合表示为权重向量：

```text
w = [w1, w2, ..., wN]
```

其中 `wi` 表示第 `i` 只股票的投资比例。

### 5.2 约束条件

本项目采用长仓、全额投资约束：

```text
wi >= 0
sum(wi) = 1
```

含义：

- 不允许卖空。
- 所有资金都分配到股票池中。
- 每只股票的权重是连续变量。

### 5.3 收益与组合波动率

设 `mu` 为股票期望收益向量，`Sigma` 为收益率协方差矩阵。

组合期望收益：

```text
E(Rp) = w^T mu
```

组合波动率 `volatility`：

```text
volatility = sqrt(w^T Sigma w)
```

外部 API 和前端字段统一使用 `volatility` 表示组合波动率；报告中可解释为“风险，即组合波动率”。不得将该字段命名为 `risk`、`sigma_p` 或其他对外字段。

### 5.4 优化目标

目标函数为最大化 Sharpe Ratio：

```text
Sharpe Ratio = (E(Rp) - Rf) / volatility
```

其中 `Rf` 为无风险收益率。若课程数据或实验设置未指定 `Rf`，默认使用 `Rf = 0`，并在报告中说明。

### 5.5 股票选择解释

PSO 求解得到连续权重后，使用如下规则解释是否选择股票：

```text
wi >= 0.01  -> 选择该股票
wi < 0.01   -> 未实质选择该股票
```

该规则用于结果展示和报告解释，不改变优化变量的连续属性。

## 6. PSO 求解方案

### 6.1 粒子表示

每个粒子表示一个投资组合权重向量：

```text
particle_position = [w1, w2, ..., wN]
```

粒子速度与位置维度均为 `N`。

### 6.2 初始化

初始化流程：

1. 随机生成非负权重向量。
2. 将权重归一化，使 `sum(wi) = 1`。
3. 初始化粒子速度。
4. 计算每个粒子的 Sharpe Ratio。
5. 设置个体最优和全局最优。

### 6.3 迭代更新

每轮迭代执行：

1. 根据惯性项、个体认知项、群体社会项更新速度。
2. 根据速度更新位置。
3. 对位置执行非负约束处理。
4. 对权重归一化。
5. 计算新的 Sharpe Ratio。
6. 更新个体最优和全局最优。
7. 记录每轮全局最优值用于收敛曲线。

### 6.4 约束处理

PSO 更新后可能产生负权重或权重和不为 1，因此每轮位置更新后执行：

- 负数权重截断为 0。
- 若截断后权重和大于 0，则归一化。
- 若截断后权重和等于 0，则使用均匀权重向量作为兜底。

### 6.5 黑盒优化限制

项目必须手写 PSO 核心算法，不使用 `scipy.optimize`、`pyswarms` 或其他直接封装优化算法的库。

NumPy 可用于向量和矩阵运算，Pandas 可用于数据处理。

## 7. 系统设计方案

### 7.1 后端设计

后端使用 Python + FastAPI + NumPy + Pandas，主要能力包括：

- 数据读取与清洗。
- 收益率矩阵计算。
- 期望收益与协方差矩阵计算。
- PSO 优化。
- 指标计算。
- API 响应封装。

### 7.2 前端设计

前端使用 Vue 3 + Element Plus + ECharts，主要界面包括：

- 参数设置区域：股票池、迭代次数、粒子数量、无风险收益率。
- 结果摘要区域：期望收益、`volatility`、Sharpe Ratio。
- 权重展示区域：展示每只股票的最优权重。
- 股票选择区域：展示权重大于等于 1% 的股票。
- 风险-收益散点图：展示不少于 2000 个 Monte Carlo 随机组合的风险与收益关系，并高亮 PSO 最优组合。
- 收敛曲线：展示 PSO 迭代过程中全局最优 Sharpe Ratio 的变化。

## 8. 实验展示方案

系统和报告至少展示以下结果：

- 最优投资组合权重。
- 被选择股票列表。
- 组合期望收益率。
- 组合风险，即组合波动率 `volatility`。
- Sharpe Ratio。
- PSO 收敛曲线。
- Monte Carlo 风险-收益散点图。

风险-收益散点图默认由不少于 2000 个 Monte Carlo 随机组合生成。图中必须高亮标记 PSO 找到的最优组合，便于说明 PSO 解相对于随机 baseline 的风险-收益位置。

## 11. 可行性分析

### 11.1 技术可行性

投资组合收益、组合波动率 `volatility` 和 Sharpe Ratio 的计算可通过 NumPy 完成。PSO 算法结构清晰，适合手写实现并用于课程展示。FastAPI、Vue 3 和 ECharts 能满足接口封装与可视化需求。

### 11.2 数据可行性

项目优先使用课程要求提供的 UCI Stock Portfolio Performance 数据集。若该数据集无法稳定获取或字段不满足计算要求，可使用 `data/sample/` 下的本地样例数据降级；只要数据包含日期、股票标识和价格字段，即可计算收益率并进入优化流程。降级方案必须在实验报告中说明。

### 11.3 展示可行性

投资组合权重、Monte Carlo 风险-收益散点图和收敛曲线均适合图形化展示。散点图中高亮 PSO 最优组合，能清楚体现“收益最大化与风险控制”的课程主题。

## 12. 修订后冻结点

- 采用连续权重投资组合模型。
- 使用 Sharpe Ratio 作为核心优化目标。
- 使用 PSO 作为核心求解算法。
- 数据源优先使用 UCI Stock Portfolio Performance 数据集，必要时降级为 `data/sample/` 下的本地样例数据；阶段一算法原型可使用模拟数据。
- 日度价格数据按 252 个交易日年化。
- 外部 API 和前端字段使用 `volatility` 表示组合波动率/风险。
- 风险-收益散点图默认使用不少于 2000 个 Monte Carlo 随机组合，并高亮 PSO 最优组合。
- 使用 1% 阈值解释股票选择结果。
- 15% 单票仓位上限不属于 V1 核心约束，只能作为 V2 可选扩展记录。
- 后端采用 Python + FastAPI + NumPy + Pandas。
- 前端采用 Vue 3 + Element Plus + ECharts。
- 不引入黑盒优化库。
